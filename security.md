# Security Policy

Details for submitting security related issues

## Supported Versions

The following versions are maintained under LTS and receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.34.x  | :white_check_mark: |
| 0.33.x  | :white_check_mark: |
| 0.32.x  | :white_check_mark: |
| 0.31.x  | :white_check_mark: |
| 0.30.x  | :white_check_mark: |
| 0.29.x  | :white_check_mark: |
| 0.28.x  | :white_check_mark: |
| 0.27.x  | :white_check_mark: |
| < 0.27  | :x:                |

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately through GitHub Security Advisories:

https://github.com/sinclairzx81/sinclair-typebox/security/advisories/new
